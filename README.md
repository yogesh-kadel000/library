** Library Management System

A comprehensive full-stack application for managing library operations, including book inventory, member accounts, borrowing/returning, and administrative controls.

** Features

- 📚 **Book Management** - Add, update, and organize library inventory
- 🔄 **Borrowing & Returns** - Track book loans and returns with due dates
- 📊 **Search & Filtering** - Quickly find books by title, author, ISBN, or category
- ⏰ **Due Date Tracking** - Automated reminders and overdue management
- 📈 **Analytics Dashboard** - View library statistics and popular books
- 🔐 **Role-Based Access** - Admin, librarian, and member roles with permission 
### For Admins
1. Log in with admin credentials
2. Navigate to "Members" to register new library members
3. Go to "Books" to add new inventory
4. Monitor dashboard for library statistics

### For Librarians
1. Check "Pending Requests" for new member applications
2. Process book borrowing and returns
3. Send overdue reminders to members
4. Generate daily/weekly reports
